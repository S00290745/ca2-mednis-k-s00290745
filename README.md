About
A text based game about collecting treasure tokens by solving clues at each location

How to play
1. Enter your name
2. Solve clues at each location to collect treasure
3. Use the menu to solve clues, get hints, travel, view progress or quit
4. Collect and five treasures and go back to students union to win

Additional Feature(Score)
You start with 100 points and earn 10 points per treasure. You lose five points for each hint and the score cannot go below 0
